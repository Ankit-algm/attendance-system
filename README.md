# Smart Attendance & Marks System

A desktop app built with Python and Tkinter that lets a teacher mark daily attendance, manage student marks, view charts, and export PDF reports. Made as my Class XII Informatics Practices project.

## Features
- Password-protected teacher login
- Mark daily attendance (saved month by month)
- View monthly attendance records
- Attendance summary chart (flags students below 75%)
- Add or remove students and modify marks
- Marks analysis chart
- Export an attendance and marks report as PDF

## Tech Used
Python, Tkinter, pandas, openpyxl, Matplotlib, fpdf2. Data is stored in Excel files.

## How to Run
1. Install Python 3.
2. Download attendance_system.py and requirements.txt into one folder.
3. Install the libraries: pip install -r requirements.txt
4. Run the program: python attendance_system.py
5. Log in with the demo password: teacher123

The student data file is created automatically on the first run.
